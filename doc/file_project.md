# proxy.rs
Основные компоненты и их взаимодействие:
1. RateLimiter - реализует ограничение частоты запросов
Хранит временные метки запросов в HashMap

Проверяет лимиты на основе временного окна

Поддерживает отключенное состояние (disabled)

2. RequestContext - контекст запроса
Хранит состояние обработки текущего запроса

Содержит BodyInspector для накопления тела запроса

Собирает информацию о нарушениях WAF

3. MyProxy - основной прокси-класс
Управляет WAF движками для разных upstream

Реализует rate limiting на двух уровнях (сервер и upstream)

Поддерживает горячую перезагрузку правил через SIGHUP

4. ProxyHttp trait implementation - обработка запросов
request_filter: проверка заголовков и URI через WAF, rate limiting

request_body_filter: проверка тела запроса после полного получения

response_filter: добавление rate limit заголовков в ответ

5. Поток обработки запроса:
Клиент отправляет запрос

request_filter: проверка rate limit + WAF на заголовках/URI

Если тело есть: request_body_filter накапливает чанки, проверяет WAF на полном теле

upstream_peer: выбирает бэкенд

Запрос проксируется

response_filter: добавляет rate limit заголовки

Ответ отправляется клиенту
